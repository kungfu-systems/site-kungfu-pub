# Security

Do not include secrets, private logs or personal recruitment data in source or browser bundles. Use the repository's private vulnerability-reporting facility when available; otherwise contact a repository maintainer privately without posting exploit-sensitive details publicly.

The preview has no server-side API, accounts, or execution sandbox. External links are opened with `noopener noreferrer`. Browser-local learning progress is user-controlled and is not a credential or certification record.
