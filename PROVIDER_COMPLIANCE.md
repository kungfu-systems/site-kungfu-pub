# Provider boundaries

The site links to external documentation and recruitment entry points. It does not proxy provider APIs, scrape authenticated data or redistribute external course bodies. Provider access, terms and availability remain controlled by their respective operators.

Any future collection or API integration must document source scope, allowed access, provenance and update behavior before release.
